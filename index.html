Workflow

How the System Works

Three straightforward steps to verify a product identifier against registered system records.

1

Enter or Scan Code

Type the unique authentication code printed on the drug package or scan its QR code using your device camera or an uploaded QR image.

2

Database Lookup

The system queries the drug registry to check record validity, expiry date, suspension status, and prior verification checks.

3

Review Result or Report

Inspect manufacturer, batch, and date details immediately. If a code is invalid or suspicious, log a report for administrative review.

System Capabilities

Core Modules & Features

Designed to align with the System Analysis, Design, and Implementation documented in the project chapters.

Instant Code Verification

Distinguishes between valid, previously verified, expired, suspended, and unregistered authentication codes.

QR Generation & Scanning

Automatically generates downloadable QR codes for newly registered drugs and supports browser-based camera/image scanning.

Verification Audit Trail

Every manual or QR verification attempt is logged with timestamp and outcome for administrative monitoring.

Drug Record Management

Administrators can register, edit, suspend, reactivate, and delete drug records with duplicate-code prevention.

Suspicious Drug Reporting

Public reporting form generates unique reference numbers and lets administrators track investigation status.

Dynamic Admin Dashboard

Real-time statistics cards and filterable tables for monitoring drug records, verification logs, and reports.

Found a Suspicious or Unregistered Drug?

Use the Suspicious Drug Reporting module to record details such as drug name, location, and description of suspicion. A unique reference number will be generated for tracking and review.
